# 📦 Sandbox: AI時代の安全なシェル環境

`sandbox` は、AIが生成したコマンドや不慣れなシステム操作を、**「安全に、かつ可視化された状態で」**実行するためのポータブルなシェルスクリプトです。

産業医が現場の安全を確保するように、Linuxデスクトップ上での「ヒヤリハット」を未然に防ぎ、すべての作業を「作業日誌（ログ）」として記録します。

## ✨ 主な機能

### 1. 🔍 実行前プレビュー (Safety Check)
`rm` コマンドを実行する際、実際にどのファイルが操作されるのかを事前に一覧表示します。ワイルドカード（`*`）の誤爆による意図しない消去を物理的に防ぎます。

### 2. 🛡️ システム保護 & 自動バックアップ
`/etc`, `/boot`, `/usr` などのシステム重要ディレクトリへの書き込みを制限します。また、ファイルを移動（`mv`）やコピー（`cp`）する際は、自動的に `~/.sandbox_backup/` へ退避させます。

### 3. ♻️ 不可逆削除の禁止
`rm` を直接実行せず、`trash-cli`（ゴミ箱）へ送ります。万が一の操作ミスでも、GUIのゴミ箱から簡単に復元可能です。

### 4. 📝 自動作業日誌 (Audit Log)
セッション中のすべての入出力（コマンドと実行結果）を `$HOME/.sandbox_logs/` に自動保存します。後でAIに作業内容を解析させたり、自分の備忘録として振り返ることが可能です。
